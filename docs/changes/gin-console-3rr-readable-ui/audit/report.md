# gin-console UI audit

Scope: 47 pages x 9 widths (390, 768, 1024, 1280, 1440, 1600, 1920, **2000**, 2560) x light and dark = 846 runs, projects `example` and `qwikfone`.
Dark theme: `localStorage["gin-console-theme"]="dark"` (frontend/src/app/theme.ts), toggles `html.dark`.
Rerun: `cd /tmp/ui-audit; NODE_PATH=/home/gin/scotty/node_modules node run.js <widths> <themes> [pageRegex]`.
`FAST=1 WAIT=10000` is needed for `/`, because the projects page loads slowly.
Then `node agg.js [overlap|shape|spill|contrast|labelvalue|emphasis]` dedupes.
Files: pages.js (page list), inpage.js (the checks), out/*.json (raw findings), full/*.jpg (full-page shots), shots/*.png (cropped evidence, named `<page>__<width>__<theme>__<category>-<hash>.png`).
Gantt = frontend/src/features/milestones/GanttChart.tsx. Bead meta line = frontend/src/features/beads/BeadDetailPage.tsx.

## Checks that found nothing

- Page-level horizontal scroll: none at any width (`documentElement.scrollWidth <= innerWidth`).
- Contrast below WCAG thresholds: only C1. All `text-muted-foreground` text measures >=6.2:1 in light and dark, and badges, Gantt text and warning text (`text-state-blocked`) pass.
- Dark theme: same findings as light, apart from the C1 ratio. No dark-only spill, overlap or contrast problem.
- `/my-tasks`, bead graph pages (`/beads/*/graph`) and the retro tab: no overlap or spill, other than the graph node link counts ("8 links" x "2 links", `fill-current text-[10px]` in bead-graph-qwik at >=1024, nodes closer than their labels). I did not confirm it visually.
- 390px: the only hits were the fixed bottom nav (ignored; the script treats fixed elements as another layer).

## Detector caveats

- The Range rects of `truncate` text are clipped to the overflow ancestor, so ellipsized titles are not reported. The spill check found G1 only through the shape check (text x bar/line), because the row uses nested flex items with no overflow box. L3-type hits are partly clipped-text false positives.
- Emphasis findings are keyword-based (pt, estimate, blocked, due, P0-P3, closed, ...). Treat them as a worklist, not defects.
