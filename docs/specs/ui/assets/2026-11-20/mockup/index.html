Graph view: lanes as coloured containers

Scope ex-e12 (Team checkout) with "Show closed" on. Each lane's tracks sit in one container with its own background colour and a header (name, state, holder, closed/total). The merge gate is no longer a node: it is a chip on the arrow between two lanes. Tracks without a lane sit in a neutral dashed "No lane" container.

example › ex-e12

A · Lanes as columns

  • One vertical container per lane; the graph keeps flowing top → bottom by dependency layer.
  • Lanes are ordered so a lane that waits sits next to the lanes it waits for (be, qa, fe, infra).
  • Close to the Lanes view, turned 90°: easy to scan "who does what, in which order".

B · Lanes as clusters

  • Each lane is a box laid out by the dependencies between lanes; tracks run left → right inside it.
  • Shows "which lane waits for which" as a small graph of lanes.
  • Wider; more boxes to move when many lanes exist.

Colours

  • Categorical palette (validated for colour-blind separation), assigned by lane name in the epic so a filter never repaints a lane.
  • Pale tint as background, stronger tone as border and swatch; every container is labelled, so colour is never the only cue.
  • Node state keeps its own 4px edge, icon and word.
