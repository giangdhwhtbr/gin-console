Strung

Tokens for gin-console. Beads are gemstones on a thread: the thread is the one identity colour, each gem says a state, and a strand of beads is how progress is drawn everywhere.

Palette

Neutrals stay cool and quiet. Amethyst marks where you are and what you can do. The four gems are reserved for state and never decorate.

State: shape, word and colour together

The glyph's fill is the progress of that bead, so the state reads without colour. Done is always jade, in every list, chart and Gantt.

Type scale

Recursive, one family in three voices: Sans for reading, Mono for ids, a touch of Casual for page titles. Base 14px, ratio about 1.25.
